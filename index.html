Crane Clearance Checker

1. Get a crane model

Opens 3D Warehouse in a new tab — there's no public API for it, so search/download stays manual. Download as Collada (.dae) or SketchUp (.skp), then upload it into this project's Files the normal way. Once it's converted, use the placement tool below.

2. Place the crane

3. Generate swing envelope

Import the downloaded .obj into this project the same way as the crane model, then place it at the crane's base point (step 2). It represents the full swept volume of the boom.

4. Run the clearance check

In Connect's Clashes panel, create one Clash Set: swing-envelope solid vs. your design/site model, mode = clearance, with your minimum distance. This is currently a one-time manual step — see PLAN.md §2.3 for why.
